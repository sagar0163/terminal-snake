# Contributing to Terminal Snake

Thanks for wanting to contribute!

## Setup

```bash
git clone https://github.com/sagar0163/terminal-snake.git
cd terminal-snake

# Run the game
python snake.py
```

## Making Changes

1. Fork the repo
2. Create a branch: `git checkout -b feature/feature-name`
3. Make improvements
4. Commit: `git commit -m "feat: add new feature"`
5. Push to main: `git push origin main`

## Ideas for Contributions

- 🎮 Multiplayer mode
- ⚡ Power-ups
- 📊 Score leaderboard
- 🎨 Custom themes
- 🔊 Sound effects
- 🌍 Level editor

## Commit Types

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `refactor:` code refactoring
