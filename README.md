# Snake Game 🐍

Classic Snake game for Linux terminal - Enhanced Edition v2.0!

## Version 2.0 - Power-Up Edition

### New Features in v2.0

| Feature | Description |
|---------|-------------|
| **Power-ups** | Shield, Cut, Slow abilities |
| **Achievements** | Unlock achievements while playing |
| **Special Fruits** | Speed boost, slow motion, bonus points |
| **Wall Wrap** | Pass through walls with shield |
| **Visual Effects** | On-screen effects and feedback |
| **Enhanced UI** | Better score display and controls |

### Controls

| Key | Action |
|-----|--------|
| W/↑ | Move up |
| S/↓ | Move down |
| A/← | Move left |
| D/→ | Move right |
| P | Pause |
| Q | Quit |
| SPACE | Restart |

### Fruits & Effects

| Fruit | Points | Effect |
|-------|--------|--------|
| 🍎 Apple | 10 | Normal |
| 🍊 Orange | 15 | Normal |
| 🍇 Grapes | 20 | Normal |
| ⭐ Star | 30 | Speed boost |
| 💎 Diamond | 50 | Bonus |
| 🐢 Turtle | 10 | Slow down |

### Power-Ups

| Power-up | Effect |
|----------|--------|
| 🛡️ Shield | Pass through walls (5s) |
| ✂️ Cut | Halve snake length (+50 pts) |
| ⏰ Slow | Slow down for easy points |

### How to Run

```bash
# Run the game
python3 snake.py
```

### Requirements

- Python 3.6+
- Linux terminal with curses support

### Achievements

- 🎉 Get 5 segments
- 🌟 Get 10 segments  
- 💯 Score 100 points
- 🏆 Score 500 points
